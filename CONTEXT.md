# Thinktable — Architecture Context

Official product terms: **`DEFINITIONS.md`**.

## Product north star

Thinktable is a spatial mind-map on **pages** (see `DEFINITIONS.md`):

1. **Keeps first-class local content** — frames (boxes holding TipTap blocks), pages (titled frames with their own page), chat panels, flashcards, and drawings work without Notion (current behavior remains).
2. **Optionally connects Notion** — users OAuth-connect their workspace (Mindmap.so-style), pick pages, map them on the board, edit on-site, and sync both ways.
3. **Exposes an MCP server** — external AIs (Cursor, Claude, etc.) can create/edit mind maps via tools, using the user’s Thinktable account (and optional Notion connection).

## Ownership split

| Concern | Source of truth |
|---|---|
| Page / frame **content** (when Notion-linked) | Notion (bidirectional sync via API) |
| Spatial **layout**, threads, page metadata | Thinktable |
| Local-only frames (no Notion link) | Thinktable only |

## Auth / Notion connect (MVP)

- Public Notion OAuth connection (`owner=user`).
- Capabilities: read + insert + update content; view workspace users (as needed).
- Redirect: `{SITE_URL}/api/notion/callback`.
- Tokens stored in `notion_connections` (service-role access only; not exposed to browser).
- Top bar **Notion** button starts connect / shows connected state (same OAuth UX Notion hosts — workspace picker → permissions → select pages).
- After connect / **Import pages**: opens a Mindmap.so-style picker with Notion **tree** (nested pages), search, **Add frame** (Notion page or picked DB → title-variant `pageLink` frame like local page blocks + nested Thinktable page whose page-body holds the Notion content / `databaseBlock`; `notionPageId` / `notionUrl` for sync; same open menu as local pages + Notion icon right of open), and **Generate mindmap** (selected page + descendants — each as one pageLink frame). Also creates nested Thinktable pages in the nav (linked via `linkedPageId` / `sourceBlockMessageId`). Nested Notion **databases** inside a page body stay as TipTap `databaseBlock` atoms (table icon + title + Notion icon). Legacy sole-`databaseBlock` map frames migrate to `pageLink` on load via `ensureNotionMapFrameIsPageLink` / `migrateSoleDatabaseBlockToPageLink` (`lib/notion/migrate-frame.ts`) — including frames that never got `linkedPageId`.

## MCP (next phase)

- Per-user API keys / OAuth for MCP clients.
- Tools: list maps, create/link nodes, import Notion page, update page content, set layout.
- MCP writes go through Thinktable APIs; Notion writes use the stored connection when the node is Notion-linked.

## Non-goals (for this slice)

- Full Notion editor parity on day one.
- Replacing local notes with Notion-only.
- Marketplace listing / Notion security review (later for public distribution).

## Key env vars

- `NOTION_CLIENT_ID`, `NOTION_CLIENT_SECRET` — public connection OAuth.
- `NEXT_PUBLIC_SITE_URL` — redirect base (local: `http://localhost:3031`).
- Existing Supabase + OpenAI vars unchanged.

### Notion Developer portal setup (one-time)

1. Open [Notion Developer connections](https://www.notion.so/developers/connections) → create **Public connection**.
2. Capabilities: Read content, Update content, Insert content; user info as needed.
3. Redirect URI: `http://localhost:3031/api/notion/callback` (add prod URL later).
4. Copy OAuth client id + secret into `.env.local` as `NOTION_CLIENT_ID` / `NOTION_CLIENT_SECRET`.
5. Restart `npm run dev`. Top bar **Notion** button starts the hosted OAuth UI (workspace → permissions → select pages).

## Naming

Official terms live in **`DEFINITIONS.md`**. Short form:

| Official | Meaning | Code today |
|---|---|---|
| **Page** | The canvas (`/board/{id}`) | `conversations` |
| **Frame** | Box holding text (one or more **blocks**) | RF `chatPanel`, `metadata.isBlock` |
| **Block** | TipTap line + ⋮⋮ (not the box) | `EditorBlockRef`, `tiptap-block-handles` |
| **Thread** | Line between frames | RF `Edge`, `panel_edges` |
| **Connection point** | Knob that starts/receives a thread | RF `Handle` |

No “block group” type — multiple blocks in a frame is still a frame. RF `blockGroup` is legacy wrapper chrome. `metadata.isBlock` means **frame**, not TipTap block. Select **frame** before caret; ⋮⋮ drag = **block** only when armed via ⋮⋮ click, else **frame**. Frame **select** is click-release only (RF mousedown select blocked); mid-press hides selection chrome except on resize/⋮⋮/rotate chrome (`pressing` must not unmount `NodeResizeControl`). **move** shows a transient blue box only and never leaves the frame selected.

- Empty **page** left-click (no frame selected) places an **I-bar + ⋮⋮ grip** at the click (`board-flow` `iBarPosition`) — not an Item/Flashcard menu. Type to create a **frame** at that point, or click the grip to spawn an empty frame immediately (`createBlockAtFlowPosition`); both use `metadata.position` + `fadeIn` (auto-focus). **I-bar typing is continuous**: first keystroke **optimistically** mounts the RF frame at the I-bar (client UUID + cache patch) with typed text already in content — no 300ms opacity hide / fade blink; further keys buffer only until TipTap focuses, then capture releases so typing is normal. Persist to `messages` in the background. Deselect click does not place the I-bar; Escape dismisses. Double-click also places the I-bar. Flashcards stay on the Insert toolbar. On frame deselect (click away / Escape), empty top-level TipTap textblocks are pruned (`pruneEmptyTextblocks`); a frame whose **only** remaining block is empty is deleted — `tt-delete-empty-frame` → `deleteNodesByIds`; skips page-body, titled, and linked-page frames (those still prune blank lines). **Deselect vs pageLink:** `onEditorActiveChange` must treat only non-empty **TextSelection** as “has selection” — a `pageLink` **NodeSelection** is `from≠to` and used to immediately re-select the frame after a pane click. Also show for the **focused/caret block**. Grip stays clickable because X no longer clears hover. Re-measure on TipTap `transaction` + `ResizeObserver`. **Select frame before caret/text** (unselected TipTap mousedown does not `stopPropagation` / does not place I-bar — RF selects + drags). **⋮⋮**: click arms that **block** (+ actions menu; selection wash persists after menu close); drag moves the **block** only when armed (`nodrag` while armed). Unarmed ⋮⋮ drag (or any drag on an unselected frame) moves the **frame**. Armed drag → dashed drop line (same-frame reorder or drop into another frame’s editor) or onto empty page → new **frame** (`htmlForEditorRange` + `newBlockMetadata`) and the source range is deleted. Menu: `BlockActionsMenu` fixed mode; `openLeft` → opens **left of the frame** when there's room, else right of the handle — opposite the right-anchored selection popup. **Empty-block keys** (`lib/tiptap/empty-block-backspace.ts`): **Backspace** deletes that **block** only and moves the I-bar to the previous line (pageLink → title end); no-op on a fresh frame’s sole empty block. **Enter** on an empty block is a no-op (does not `splitBlock` another blank line); Enter after text still creates the next block. StarterKit `trailingNode` is **off** — it was re-inserting an empty `<p>` after `pageLink`/atoms so Backspace removed the block then immediately restored the blank line. - **Frame lock**: Default **locked** (`metadata.frameUnlocked: false`). Locked + content → **proportional resize only** (`keepAspectRatio` + `frameScale`). Locked **hugs width AND height** to natural content (`resizeDimensions` = intrinsic × `frameScale` + border, via `scaledFrameSize`) on lock/relock/type — no longer keeps the taller resize box. Relock hugs both. Padding lives **inside** the scaled wrapper + layout spacer so CSS `scale` still occupies space. Unlock **keeps the current visual box + `frameScale`** (blocks stay the size they were adjusted to while locked — no snap-back to a pre-lock shape). `unlockedFrameSize` / `unlockedFrameScale` are still refreshed on unlocked resize-end / unlock for metadata continuity but are **not** used to resize on unlock. Unlocked: free resize; if frame < scaled content it **clips** (inner overflow hidden) with a **soft edge fade** (`clipFadeMaskStyle` / `mask-image` on overflowing right/bottom so half-cut glyphs dissolve instead of chopping). **Hover ~500ms** an unlocked clipped frame to **preview the full blocks** (`showClipPreview` after dwell: temporarily unclip + drop fade + backdrop + raise RF node z-index; leave cancels immediately; saved size unchanged). The old expand/collapse **overflow caret was removed** (`handleToggleOverflow` / `frameExpanded` gone) — **lock = fit-to-content, unlock = keep current size + free resize/clip** (`collapsedFrameSize` fully removed — state, load, and persist). Selection chrome scales with **frame size** via shared `frameUiScale` (shrink when frame < ref/0.7 wide, floor 0.55; grow `widthRatio^0.85` up to 4× on large frames): corner resize dots, blue resize **lines** (`--tt-frame-line-w` / `--tt-frame-line-hit`), and connection **indicators** (dot size + `INDICATOR_OUTSET`). Rotate/lock/wrap uses the same fit × soft zoom comfort (`1/max(1, rfZoom^0.35)`); gap clears the scaled bottom indicator; `z-index` below indicators. Lock/wrap require content — `isBlockContentEmpty` treats `pageLink`/`databaseBlock` atoms as non-empty (title lives in attrs). The ⋮⋮ **block grips + add-block line** (`tiptap-block-handles.tsx`) are counter-scaled by the measured container local→screen scale (`getBoundingClientRect().height/offsetHeight` = zoom × frameScale); a `useStore` zoom subscription re-renders them to re-measure on zoom. They use `transform-origin: center` and a **comfort** scale `1 / max(1, √scale)`: zoomed **out** scale = 1 (grip rides WITH content); zoomed **in** it counter-scales by `1/√scale` (screen size grows only ∝ √zoom). **Horizontal**: centered in the gutter — `left = GUTTER(24)/2 − GRIP_W(20)/2` — so it stays midway between the frame's left edge and the block-text left at every zoom (local, rides with content). **Vertical**: centered on the FIRST **rendered** text line — `top = lineCenter` + `translateY(-50%)`, where `lineCenter` is the topmost Range client rect of the block text (for pageLink: `.tt-page-link-label`, so the flex-centered icon isn’t used), fallback to `block.top + firstLineH/2`. The add-block line shares the same gutter-center `left` + `origin: center`. The right-click frame menu (`components/block-actions-menu.tsx` → `BlockActionsMenu`, dispatched by `handleBlockAction`) has a **Frame shape automations** entry (beta **stub**, action `frameShapeAutomations`) — the future home for saved frame-shape rules; currently just closes the menu. Unlocked chrome also shows **Wrap text** (`WrapText`, right of lock) → `metadata.frameTextWrap`: soft-wrap in the frame width; **height is free like non-wrap clip** — a frame shorter than the wrapped content **clips vertically** (`overflow:hidden`); hover still reveals the full wrapped blocks. Unlocked **non-wrap does NOT auto-adjust height** — free resize stays exactly where dragged (no snapping to text). Wrap **no longer auto-hugs height** (removed the continuous hug effect + resize-end hug). `contentOverflows` covers wrap (vertical only, since wrap width is fixed) and nowrap clip via `unlockedResized` (`wrapUnlocked || clipUnlocked`). **Wrap works LOCKED too** (`wrapActive` = wrap + resized, any lock state; button shows whenever selected + has content, not just unlocked): toggling/keeping wrap wraps at the **current frame width** and keeps it. **Relock while wrapped keeps wrap** — width stays the unlocked wrap width, height hugs the wrapped content (locked auto-hug keeps `prev.width` when `frameTextWrap`); relock nowrap still hugs both. **Wrap column width** (`metadata.wrapColWidth`, unscaled px) is the source of truth for the wrap point. Captured when wrap is turned on (or updated on an **unlocked**-wrap resize-end = "the point set while unlocked"); persisted; never cleared on unwrap. **Locked** wrap sets `wrapContentWidth = wrapColWidth` **directly** (fixed columns) — NOT derived from the live frame width — so proportional resize can't reflow characters. **Locked-wrap resize scales PROPORTIONALLY**: `handleResize` sets `frameScale` (keepAspectRatio) and derives the box as `wrapColWidth × frameScale + 2` (both dims), so width/text scale together with **zero character reflow**; `handleResizeEnd` hugs the same scaled columns + scaled wrapped height. **Unwrap→rewrap while locked returns to the same point**: rewrap reuses the stored `wrapColWidth` (via the toggle's double-`rAF` re-hug → `width = wrapColWidth × frameScale + 2`), wrap-off still hugs both dims to nowrap text. **Unlocked** wrap still derives `wrapContentWidth` from the live width (drag = re-wrap) and records the new `wrapColWidth` on resize-end. `handleResizeEnd` now persists `frameTextWrap` in **either** lock state (was forcing `false` when locked → wrap lost on resize). **Toggling wrap while locked** seeds a box + `isUserResized` (locked frames hugging content have no `resizeDimensions` yet) and, after a double-`rAF` reflow, deterministically re-hugs: wrap-on keeps width + hugs height, **wrap-off hugs BOTH width and height to the nowrap text** (fixes locked-unwrap leaving stale wrapped height). `wrapContentWidth` + `singleLineUntilEnter`/`data-block-resized` key off `wrapActive` (not `wrapUnlocked`). **Rotate / wrap / lock** chrome only when the frame is **selected** (not on unselected hover). Frame content vertical pad is **equal 4px** top/bottom. Persist `frameUnlocked`, `frameTextWrap`, `frameScale`, `resizeDimensions`, `collapsedFrameSize`. Block line-height stays **1.7** (height-based line-height broke lock-to-text). Frame **min width**: pageLink frames → ⋮⋮ + icon + open-menu; plain frames → ⋮⋮ + ~3ch (`blockMinFrameWidth`). Locked width hug measures **natural** text via **Range glyph extents** (icon box + gap + label Range for pageLink; longest line Range for text) — never `offsetWidth`/`scrollWidth` of `width:100%` children (those report the frame width → too wide/narrow). Hug width = `padL + gutter + maxLine + iconInset` where **gutter** is read from the ⋮⋮ handles row via `pm.closest('.relative')` (NOT `contentFit.querySelector('.relative')`, which matched the outer `containerRef` → pad 0 → frame ~24px too narrow / right-clipped) and **iconInset** (`padL + GRIP_ICON_INSET`) makes the widest line's right gap equal the frame-left→⋮⋮-icon left gap. Locked contentFit uses `w-max`. **Frame-scale spacer (`applyFrameScale`, `frameScale≠1`)**: content lays out **unscaled** at `frameInner ÷ frameScale` (`wrapContentWidth`, both wrap AND clip) so the CSS `scale()` lands exactly on the frame-inner box — `w-full` here double-scaled and clipped the text. Spacer width/height = frame inner for unlocked resized; scaled content for locked.
- **Blocks vs frames**: A **frame** is a box on a **page**. A **block** is a TipTap unit inside the frame’s editor. The ⋮⋮ grip is on each **block** (`components/tiptap-block-handles.tsx`), not on the frame. Hover a line → grip in the left gutter; click → blue wash on **that** block + actions menu (arms block); drag ⋮⋮ → that block only when armed, else the **frame**. Turn into runs TipTap commands on the selected block (`lib/tiptap/block-selection.ts`); Page / Page in still promote the host **frame** (`lib/blocks/turn-into.ts`). **In-frame multi-select** (same frame only): plain grip-click = single block + menu; **Shift**-click = range to anchor (`collectBlocksBetween`); **Cmd/Ctrl**-click = toggle. Selected blocks keep a persistent grip + multi-range wash (`setEditorBlockHighlightRanges`); a plain click on an already-selected grip opens a group menu whose actions (delete/duplicate/turn-into) apply to all. Group `Turn into Page` = `turnSelectionIntoPage`: new child page from the combined block HTML (blocks stay) + a title `pageLink` on top. `pageLink` atoms are `isHandleBlockType` (grip via DOM rect). NOTE: RF key props (`multiSelectionKeyCode`/`selectionKeyCode`) MUST be stable module constants (`MULTI_SELECT_KEYS`/`SELECTION_BOX_KEYS`) — inline array literals loop RF's `useKeyPress` (Max update depth). Multiple blocks in one frame is still a frame (no “block group” type). RF `blockGroup` is a legacy dashed wrapper around several frames (`draggable: false`; membership `metadata.blockGroupId`; page-absolute positions). Move via the **dashed padding ring**. Drag a **frame** (not ⋮⋮) onto the wrapper ~20% overlap to attach, off onto the page to detach; empty wrappers delete. Wrapper `pointer-events: none` + ring `auto`. Wrapper `zIndex: 0`, frames `1`. Drop-target highlight via `className: drop-target`.
